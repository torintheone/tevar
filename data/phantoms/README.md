# Синтетические фантомы

Файлы в этой папке создаются генератором и не хранятся в git:

```
cd core
python -m aortaplan_core.phantoms            # все стандартные фантомы
python -m aortaplan_core.phantoms --list     # список
python -m aortaplan_core.phantoms --only torus_arc helix
```

Для каждого фантома пишутся `<имя>.nrrd` (объём, HU, int16, пространство LPS — как у DICOM)
и `<имя>.truth.json` (истинные значения в RAS, мм: центральная линия, нормали, полуоси слоёв,
аналитические диаметры, площади и длины).

Стандартный набор:

| Имя | Что проверяет |
|---|---|
| `straight_tube`, `straight_tube_realistic`, `straight_tube_oblique_aniso` | диаметры, геометрия сетки (косая трубка, анизотропные воксели) |
| `elliptical_tube` | эллиптическое сечение 30 × 20 мм: мин./макс. диаметр |
| `torus_arc`, `helix` | длины вдоль линии и по кривизне, ориентация срезов |
| `aortoiliac`, `aortoiliac_bone` | бифуркация, протекание в «позвонок», кальцинаты |
| `aneurysm` | веретенообразная аневризма 60 × 54 мм с эксцентричным «тромбом» (40 HU) в жире (−100 HU): наружный контур |
| `aneurysm_calcified` | то же + кальцинированная бляшка на наружной стенке |
